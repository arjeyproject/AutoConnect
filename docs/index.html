AutoConnect

Private routing, one tap away.

This guide covers Ubuntu setup, native asset verification, signed APK builds and server compatibility.

1. Prepare Ubuntu

sudo apt update
sudo apt install -y git curl unzip tar build-essential libssl-dev pkg-config openjdk-17-jdk
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
export PATH="$ANDROID_SDK_ROOT/cmdline-tools/latest/bin:$ANDROID_SDK_ROOT/platform-tools:$PATH"
yes | sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0" "ndk;27.2.12479018"
export ANDROID_NDK_HOME="$ANDROID_SDK_ROOT/ndk/27.2.12479018"

2. Clone and build

git clone https://github.com/arjeyproject/AutoConnect.git
cd AutoConnect
./scripts/fetch-native-assets.sh
gradle --no-daemon testDebugUnitTest lintDebug assembleDebug

The fetch script downloads Aether for ARMv7, ARM64 and x86_64, verifies upstream SHA-256 files, clones HEV at a pinned commit and compiles the JNI bridge. A mismatch stops the build.

Release

export ANDROID_KEYSTORE_PATH=.signing/autoconnect.jks
export ANDROID_KEYSTORE_PASSWORD='secret'
export ANDROID_KEY_ALIAS=autoconnect
export ANDROID_KEY_PASSWORD='secret'
./scripts/package-release.sh

3. Server compatibility

Important: AutoConnect currently speaks MASQUE, WireGuard and Gool through the Aether core. Custom endpoint is not a generic VLESS/Reality or arbitrary sing-box JSON parser. A sing-box or Xray server is separate, not a direct AutoConnect backend.

For compatible clients, install sing-box on Ubuntu:

sudo apt update && sudo apt install -y curl unzip
bash <(curl -fsSL https://sing-box.app/deb-install.sh)
sudo install -d -m 0750 /etc/sing-box
sudo nano /etc/sing-box/config.json
sudo systemctl enable --now sing-box
sudo systemctl status sing-box --no-pager

Use official documentation for the inbound, TLS certificate, firewall and compatible client profile. Do not expose a management port.

4. Connect Android

  1. Install Universal or the matching ABI APK.
  2. Choose Device VPN and approve Android's VPN prompt.
  3. Start with Gool and Turbo.
  4. Tap the aperture and inspect Activity for gateway tests.
  5. Use Smart to benchmark all three protocols.

SOCKS5 mode exposes 127.0.0.1:1819.
