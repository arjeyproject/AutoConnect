# Security policy

Report vulnerabilities privately to [@ArJeyDev](https://t.me/ArJeyDev), not in a public issue.

The updater accepts metadata only from api.github.com/repos/arjeyproject/AutoConnect, rejects download URLs outside the official release prefix, verifies SHA-256 and checks the installed signing certificate before installation.

Native assets are downloaded and verified at build time. The app has no account, analytics, crash reporter or custom control plane. Cloud backup and device transfer are excluded.

Only the latest published release receives fixes. AutoConnect is a transport client, not a promise of anonymity or protection for a compromised device.
